CALC ROGUELIKE — мобильный браузерный прототип

Содержимое:
- index.html — игра, интерфейс и логика
- manifest.json — метаданные веб-приложения
- sw.js — базовый кэш для офлайн-режима после первого посещения

Как проверить на компьютере:
1. Откройте index.html в браузере. Основная игра работает локально.
2. Для проверки PWA/offline режима проект нужно опубликовать по HTTPS (например, на GitHub Pages).

Как открыть на iPhone:
1. Разместить содержимое папки на HTTPS-хостинге.
2. Открыть ссылку в Safari.
3. Нажать «Поделиться» → «На экран Домой».

Это самостоятельный прототип по мотивам жанра, не копия оригинальной игры. Состояние сохраняется локально в браузере. Для публикации потребуется хостинг; архив сам по себе не создаёт публичную ссылку.
